# Примеры метаданных для магазинов приложений

## App Store Connect

### Название приложения
```
018BY
```

### Подзаголовок (до 30 символов)
```
Фотоальбомы для беременности и детства
```

### Описание (до 4000 символов)
```
018BY — это приложение для создания персональных фотоальбомов, которое поможет вам сохранить самые важные моменты жизни.

ОСОБЕННОСТИ:

📸 Создание альбомов
Создавайте красивые цифровые альбомы для беременности и детства (0-7 лет). Выбирайте из множества стильных шаблонов и дизайнов обложек.

🎨 Редактирование
Добавляйте фотографии, текст, аннотации и создавайте уникальные страницы. Используйте различные шрифты и стили для персонализации.

📄 Экспорт в PDF
Экспортируйте готовые альбомы в PDF формате для печати в профессиональных типографиях. Поддержка форматов A4 и A5.

🔔 Умные напоминания
Получайте персональные напоминания о важных моментах беременности и развития ребёнка. Никогда не пропустите важное событие.

🔄 Синхронизация
Переносите данные между устройствами через QR-код. Ваши альбомы всегда с вами, на любом устройстве.

💾 Безопасное хранение
Все ваши данные хранятся локально на устройстве. Ваши воспоминания в безопасности.

ИДЕАЛЬНО ДЛЯ:
• Будущих мам, которые хотят сохранить воспоминания о беременности
• Родителей, создающих альбомы для детей
• Семей, которые ценят традиционные фотоальбомы

Создавайте уникальные альбомы, которые станут семейной реликвией на долгие годы!
```

### Ключевые слова (до 100 символов)
```
фотоальбом,беременность,дети,альбом,воспоминания,PDF,печать,фото,семья,альбомы
```

### Категории
- Основная: Фото и видео
- Дополнительная: Образ жизни

## Примеры скриншотов

### Рекомендуемые сцены для скриншотов:

1. **Главный экран** - список проектов/альбомов
2. **Создание альбома** - выбор шаблона
3. **Редактирование** - страница с фотографиями и текстом
4. **Экспорт PDF** - экран экспорта
5. **Уведомления** - экран напоминаний
6. **Профиль** - настройки и информация

### Требования к скриншотам:

- **Качество**: Высокое разрешение, четкие изображения
- **Содержание**: Показывайте реальные функции приложения
- **Текст**: Минимум текста, максимум визуальной информации
- **Брендинг**: Используйте фирменные цвета (#C9A89A, #FAF8F5)

## Политика конфиденциальности (шаблон)

Создайте страницу с политикой конфиденциальности. Пример структуры:

```
ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ

1. СБОР ИНФОРМАЦИИ
Приложение 018BY собирает минимальную информацию, необходимую для работы:
- Фотографии, добавленные пользователем в альбомы
- Текст и аннотации, созданные пользователем
- Данные о проектах и альбомах

2. ХРАНЕНИЕ ДАННЫХ
Все данные хранятся локально на устройстве пользователя. 
Мы не передаем данные третьим лицам и не используем их для рекламы.

3. РАЗРЕШЕНИЯ
Приложение запрашивает следующие разрешения:
- Камера: для сканирования QR-кодов
- Фото библиотека: для добавления фотографий в альбомы
- Уведомления: для напоминаний о важных событиях

4. ПРАВА ПОЛЬЗОВАТЕЛЕЙ
Пользователь имеет право:
- Удалить все данные в любой момент
- Экспортировать свои данные
- Отозвать разрешения

5. КОНТАКТЫ
По вопросам конфиденциальности: privacy@ваш-домен.com
```

## Примечания

- Все URL должны быть реальными и доступными
- Email поддержки должен быть активным
- Политика конфиденциальности обязательна для публикации
- Скриншоты должны быть актуальными и показывать реальный функционал
- Описания должны быть на русском языке (или на языке целевой аудитории)
