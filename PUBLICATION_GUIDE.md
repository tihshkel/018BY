# Руководство по публикации приложения в App Store и Google Play

## Подготовка к публикации

### 1. Требования перед публикацией

#### Для iOS (App Store):
- ✅ Apple Developer Account ($99/год)
- ✅ Bundle Identifier: `com.tihshkel.x018BY`
- ✅ Иконка приложения (1024x1024px)
- ✅ Скриншоты для App Store (требуются разные размеры)
- ✅ Описание приложения
- ✅ Политика конфиденциальности (URL)

#### Для Android (Google Play):
- ✅ Google Play Developer Account ($25 единоразово)
- ✅ Package Name: `com.tihshkel.x018BY`
- ✅ Иконка приложения (512x512px)
- ✅ Скриншоты для Google Play
- ✅ Описание приложения
- ✅ Политика конфиденциальности (URL)

### 2. Настройка EAS Build

#### Установка EAS CLI:
```bash
npm install -g eas-cli
```

#### Вход в аккаунт Expo:
```bash
eas login
```

#### Создание проекта в Expo:
```bash
eas init
```

Это создаст projectId в `app.json` в поле `extra.eas.projectId`.

### 3. Подготовка иконок и изображений

#### iOS:
- Иконка: `./assets/images/icon.png` (1024x1024px)
- Splash Screen: `./assets/images/splash-icon.png` (200x200px)

#### Android:
- Adaptive Icon Foreground: `./assets/images/android-icon-foreground.png`
- Adaptive Icon Background: `./assets/images/android-icon-background.png`
- Monochrome Icon: `./assets/images/android-icon-monochrome.png`

### 4. Скриншоты для магазинов

#### App Store (iOS):
Требуются скриншоты для разных устройств:
- iPhone 6.7" (iPhone 14 Pro Max): 1290 x 2796 px
- iPhone 6.5" (iPhone 11 Pro Max): 1242 x 2688 px
- iPhone 5.5" (iPhone 8 Plus): 1242 x 2208 px
- iPad Pro 12.9": 2048 x 2732 px

#### Google Play (Android):
- Телефон: минимум 2 скриншота (16:9 или 9:16)
- Планшет: минимум 1 скриншот (16:9 или 9:16)
- Рекомендуемый размер: 1080 x 1920 px или выше

### 5. Сборка приложения

#### Development Build (для тестирования):
```bash
eas build --profile development --platform ios
eas build --profile development --platform android
```

#### Preview Build (для внутреннего тестирования):
```bash
eas build --profile preview --platform ios
eas build --profile preview --platform android
```

#### Production Build (для публикации):

**iOS:**
```bash
eas build --profile production --platform ios
```

После сборки:
```bash
eas submit --platform ios
```

**Android:**
```bash
eas build --profile production --platform android
```

После сборки:
```bash
eas submit --platform android
```

### 6. Настройка App Store Connect (iOS)

1. Войдите в [App Store Connect](https://appstoreconnect.apple.com/)
2. Создайте новое приложение:
   - Название: "018BY"
   - Основной язык: Русский
   - Bundle ID: `com.tihshkel.x018BY`
   - SKU: `018BY-001`
3. Заполните информацию о приложении:
   - Категория: Фото и видео / Образ жизни
   - Описание (до 4000 символов)
   - Ключевые слова (до 100 символов)
   - Поддержка: URL вашего сайта поддержки
   - Политика конфиденциальности: URL
   - Маркетинговый URL (опционально)
4. Загрузите скриншоты и иконку
5. Настройте ценообразование и доступность
6. Отправьте на проверку

### 7. Настройка Google Play Console (Android)

1. Войдите в [Google Play Console](https://play.google.com/console/)
2. Создайте новое приложение:
   - Название: "018BY"
   - Язык по умолчанию: Русский
   - Тип приложения: Приложение
   - Бесплатное/Платное: Бесплатное
3. Заполните информацию о приложении:
   - Краткое описание (до 80 символов)
   - Полное описание (до 4000 символов)
   - Графические ресурсы:
     - Иконка приложения (512x512px)
     - Скриншоты
     - Графический баннер (1024x500px, опционально)
   - Категория: Фотография
   - Контентный рейтинг: Заполните анкету
   - Политика конфиденциальности: URL
4. Настройте ценообразование и распространение
5. Создайте релиз:
   - Загрузите AAB файл (созданный через EAS Build)
   - Укажите версию и заметки о релизе
6. Отправьте на проверку

### 9. Политика конфиденциальности

Необходимо создать страницу с политикой конфиденциальности и указать URL в настройках приложения.

Пример содержания:
- Какие данные собираются
- Как используются данные
- Хранение данных
- Права пользователей
- Контакты для вопросов

### 10. Тестирование перед публикацией

1. **Внутреннее тестирование:**
   - Установите preview build на реальные устройства
   - Протестируйте все функции
   - Проверьте работу на разных версиях iOS/Android

2. **TestFlight (iOS):**
   ```bash
   eas build --profile preview --platform ios
   ```
   Затем загрузите в TestFlight через App Store Connect

3. **Internal Testing (Android):**
   ```bash
   eas build --profile preview --platform android
   ```
   Затем загрузите в Google Play Console для внутреннего тестирования

### 11. Обновление версий

При каждом обновлении приложения:

**app.json:**
```json
{
  "expo": {
    "version": "1.0.1",  // Увеличьте версию
    "ios": {
      "buildNumber": "2"  // Увеличьте buildNumber
    },
    "android": {
      "versionCode": 2  // Увеличьте versionCode
    }
  }
}
```

**package.json:**
```json
{
  "version": "1.0.1"  // Синхронизируйте с app.json
}
```

### 12. Полезные команды

```bash
# Проверка конфигурации
eas build:configure

# Просмотр статуса сборки
eas build:list

# Просмотр логов сборки
eas build:view [BUILD_ID]

# Обновление EAS CLI
npm install -g eas-cli@latest
```
