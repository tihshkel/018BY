# Система координат текстовых полей

## Описание

Эта система позволяет автоматически позиционировать текст в правильных местах на страницах альбомов. Когда пользователь добавляет текст, система проверяет, есть ли определенные координаты для этой страницы, и автоматически позиционирует текст в нужном месте.

## Как это работает

1. При нажатии на страницу для добавления текста система проверяет наличие координат для этой страницы
2. Если координаты найдены, текст позиционируется в ближайшем текстовом поле
3. Если координаты не найдены, используется стандартная логика позиционирования

## Структура файла

Файл `text-field-coordinates.ts` содержит координаты для всех альбомов в формате:

```typescript
{
  albumId: [
    {
      page: 1,
      fields: [
        { x: 0.1, y: 0.2, width: 0.8, label: 'Описание' },
        // ... другие поля
      ],
    },
    // ... другие страницы
  ],
}
```

## Заполнение координат

### Шаг 1: Анализ страницы

Для каждой страницы альбома нужно:

1. Открыть изображение страницы
2. Определить места, где должен начинаться текст
3. Вычислить нормализованные координаты

### Шаг 2: Вычисление координат

Используйте формулу:

```
x = позиция_от_левого_края / ширина_страницы
y = позиция_от_верхнего_края / высота_страницы
width = ширина_поля / ширина_страницы
```

### Шаг 3: Запись в файл

Добавьте координаты в файл `text-field-coordinates.ts`:

```typescript
pregnancy_60: [
  {
    page: 1,
    fields: [
      { x: 0.1, y: 0.2, width: 0.8, label: 'Заголовок' },
      { x: 0.15, y: 0.35, width: 0.7, label: 'Дата' },
    ],
  },
],
```

## Примеры

### Пример 1: Страница с одним полем в центре

```typescript
{
  page: 5,
  fields: [
    { x: 0.2, y: 0.5, width: 0.6, label: 'Основной текст' },
  ],
}
```

### Пример 2: Страница с несколькими полями

```typescript
{
  page: 10,
  fields: [
    { x: 0.1, y: 0.15, width: 0.3, label: 'Дата' },
    { x: 0.1, y: 0.3, width: 0.8, label: 'Заголовок' },
    { x: 0.1, y: 0.5, width: 0.8, label: 'Текст' },
    { x: 0.6, y: 0.85, width: 0.35, label: 'Подпись' },
  ],
}
```

## Инструменты для анализа

### Визуальный редактор (рекомендуется)

1. Откройте изображение страницы в графическом редакторе
2. Используйте инструмент измерения для определения координат
3. Запишите координаты в файл

### Интерактивный режим в приложении

1. Откройте альбом в режиме редактирования
2. Включите режим отладки (если доступен)
3. Нажмите на места, где должен начинаться текст
4. Запишите координаты из консоли

## Тестирование

После заполнения координат:

1. Откройте альбом в приложении
2. Попробуйте добавить текст в местах с определенными координатами
3. Убедитесь, что текст позиционируется правильно
4. При необходимости скорректируйте координаты

## Поддержка альбомов

Система поддерживает все типы альбомов:

- `pregnancy_60` - Дневник беременности 60 страниц
- `pregnancy_a5` - Дневник беременности A5
- `kids_48` - Детские альбомы
- `diary_interior_brown` - Дневники
- И другие альбомы из `albums/index.ts`

## Приоритет координат

1. Если найдено текстовое поле - используется его координаты
2. Если поле не найдено, но есть line guides - используется привязка к линиям
3. Если ничего не найдено - используется стандартное позиционирование по клику
