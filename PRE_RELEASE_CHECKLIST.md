## 📝 Команды для выполнения

```bash
# 1. Установка EAS CLI (если еще не установлен)
npm install -g eas-cli

# 2. Вход в аккаунт Expo
eas login

# 3. Инициализация проекта (создаст projectId)
eas init

# 4. Сборка для iOS
eas build --profile production --platform ios

# 5. Сборка для Android
eas build --profile production --platform android

# 6. Отправка в App Store (после сборки)
eas submit --platform ios

# 7. Отправка в Google Play (после сборки)
eas submit --platform android
```

## ⚠️ Важные замечания

1. **EAS projectId**: После выполнения `eas init` будет создан projectId, который нужно добавить в `app.json` в поле `extra.eas.projectId`

2. **Версионирование**: При каждом обновлении приложения увеличивайте:
   - `version` в `app.json` и `package.json`
   - `buildNumber` для iOS
   - `versionCode` для Android

3. **Тестирование**: Обязательно протестируйте приложение на реальных устройствах перед публикацией

4. **Политика конфиденциальности**: Обязательна для публикации в обоих магазинах

5. **Время проверки**: 
   - App Store: обычно 1-3 дня
   - Google Play: обычно несколько часов до 1 дня
