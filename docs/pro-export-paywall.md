# Окно экспорта Pro

Обновлено 5 октября 2026 года.

Основное окно: заголовок «Экспорт Pro», краткое описание PDF для типографии, две карточки форматов обложки и одна кнопка «Открыть Pro» с локализованной ценой App Store. Под кнопкой указана разовая оплата без подписки. «Уже покупали?» восстанавливает покупку; «Позже» закрывает окно. Электронный PDF обозначен бесплатным.

Состояния доступа показаны отдельно:

- Покупка из прежней версии: короткое объяснение, кнопка «Связаться с поддержкой» открывает https://rastr.by/, ниже — проверка покупки и закрытие. Цена и кнопка оплаты скрыты. Этот редизайн не выполняет миграцию старых транзакций.
- Покупка другого аккаунта: предлагается войти в нужный аккаунт 018BY; поддержка доступна дополнительно.
- Нет сессии: кнопка входа.
- Цена не загрузилась: кнопка проверки доступа вместо оплаты с неизвестной ценой.

Убраны повторные описания, отдельный крупный блок цены, длинная инструкция по Apple ID и самостоятельная третья кнопка «Повторить». Причина блокировки передаётся типизированным полем `purchaseBlockReason`, без разбора текста ошибки.

Сохраняется выбор ожидающего формата после покупки/восстановления. Повторные нажатия объединяются, закрытие блокируется на время запроса. Ошибка открытия сайта или запроса показывает короткое сообщение и освобождает кнопки.

Проверка: `npm run test:iap` и `npm run test:auth` проходят. Добавлены проверки главной кнопки с ценой, повторных нажатий, открытия поддержки, отсутствия повторной оплаты старой покупки, входа в другой аккаунт и восстановления цены после загрузки каталога. ESLint проходит. Общий TypeScript содержит прежние ошибки в других компонентах/e2e; изменённые файлы ошибок не показывают. iOS production JS собран в Hermes bytecode. Новый вид на физическом iPhone пока не проверен.
