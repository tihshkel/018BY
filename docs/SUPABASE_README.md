# Supabase — что подключено и что сохраняется

## Подключённые компоненты

### 1. Клиент Supabase
- **Файл:** `lib/supabase.ts`
- **Пакеты:** `@supabase/supabase-js`, `react-native-url-polyfill`
- Читает URL и ключ из `.env` (`EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY`)

### 2. Таблицы в Supabase

#### `accounts`
| Поле        | Описание                |
|-------------|-------------------------|
| access_code | Код доступа (8 символов)|
| user_name   | Имя пользователя        |
| created_at  | Дата создания           |
| updated_at  | Дата обновления         |

#### `account_sync`
| Поле        | Описание                                |
|-------------|-----------------------------------------|
| access_code | Ссылка на `accounts`                    |
| data_json   | JSON со всеми данными аккаунта          |
| updated_at  | Дата последней синхронизации            |

## Что сохраняется в облако

| Данные                 | Ключ AsyncStorage       | Описание                               |
|------------------------|-------------------------|----------------------------------------|
| Имя пользователя       | `@user_name`            | Имя из регистрации                     |
| Код доступа            | `@access_code`          | 8-символьный код                       |
| Список проектов        | `@user_projects`        | Метаданные проектов                    |
| Данные проектов        | `@project_*`            | Альбомы, секции, даты, категории       |
| Изображения проектов   | `@project_images_*`     | URI фотографий                         |
| Аннотации страниц      | `@project_annotations_*`| Тексты, позиции                        |
| Аннотации обложки      | `@project_cover_annotations_*` |                       |
| PDF путь альбома       | `@project_pdf_*`        | Путь к PDF шаблону                     |
| Напоминания            | `@reminders`            | Даты, темы, описание                   |
| Инфо о беременности    | `@pregnancy_info`       | ПДР, projectId                         |
| История экспорта       | `@export_history_*`     | Экспорты в PDF                         |
| Фото профиля           | `@user_avatar`          | URI аватара                            |
| Прочие настройки       | `@has_seen_*`           | Онбординг, модалки                     |

## Когда происходит синхронизация

### Отправка в облако (push)
1. **Уход в фон** — при сворачивании или закрытии приложения
2. **После регистрации** — сразу после ввода имени
3. **После экспорта PDF** — при сохранении в историю экспорта

### Загрузка из облака (pull)
- **Вход по коду** — при успешном вводе кода доступа на новом устройстве

## Фотографии (Supabase Storage)

При синхронизации локальные фото (`file:///...`) загружаются в Supabase Storage. В облако сохраняются URL (`https://...`), по которым изображения доступны на новом устройстве.

**Требуется:** выполнить `supabase/storage-setup.sql` для создания bucket и политик.
- **История экспорта:** `fileUri` ведёт на локальный PDF, на новом устройстве файл не откроется, но запись в истории остаётся.
- **PDF шаблоны:** `@project_pdf_*` — путь к локальному файлу, на новом устройстве может не работать.
