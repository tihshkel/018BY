# Анализ координат текстовых полей для альбомов

## Резюме

Создана система для автоматического позиционирования текста в правильных местах на страницах альбомов. Система использует предопределенные координаты текстовых полей для каждой страницы каждого альбома.

## Что было создано

### 1. Файл координат
- **Путь**: `constants/text-field-coordinates.ts`
- **Содержит**: Интерфейсы и функции для работы с координатами текстовых полей
- **Функции**:
  - `getTextFieldsForPage()` - получить поля для страницы
  - `getNearestTextField()` - найти ближайшее поле к клику
  - `getTextFieldPosition()` - преобразовать нормализованные координаты в пиксели

### 2. Интеграция в код
- **Файл**: `components/image-viewer.tsx`
- **Изменения**: При добавлении текста система проверяет наличие координат и автоматически позиционирует текст

### 3. Документация
- `docs/text-field-coordinates-guide.md` - Подробное руководство
- `constants/README-text-field-coordinates.md` - Краткая инструкция
- `scripts/analyze-text-fields.js` - Скрипт для анализа

### 4. Режим отладки
- В режиме разработки (`__DEV__`) система логирует координаты в консоль
- Это помогает определить координаты при клике на страницу

## Как заполнить координаты

### Метод 1: Использование режима отладки

1. Откройте альбом в приложении в режиме разработки
2. Включите инструмент "Текст"
3. Нажмите на места, где должен начинаться текст
4. В консоли разработчика вы увидите логи с координатами:
   ```
   [TextFields] Координаты для анализа: {
     albumId: 'pregnancy_60',
     page: 1,
     normalized: { x: 0.15, y: 0.25 },
     suggestedField: { x: 0.15, y: 0.25, width: 0.7, label: '...' }
   }
   ```
5. Скопируйте координаты из `suggestedField` в файл `text-field-coordinates.ts`

### Метод 2: Визуальный анализ изображений

1. Откройте изображение страницы в графическом редакторе
2. Определите места для текста
3. Вычислите нормализованные координаты:
   - `x = позиция_от_левого_края / ширина_страницы`
   - `y = позиция_от_верхнего_края / высота_страницы`
   - `width = ширина_поля / ширина_страницы`
4. Запишите в файл координат

### Метод 3: Использование инструментов измерения

1. Используйте инструменты для измерения координат (например, в браузере DevTools)
2. Определите координаты в пикселях
3. Нормализуйте координаты относительно размеров страницы
4. Запишите в файл

## Формат записи координат

```typescript
export const TEXT_FIELD_COORDINATES: Record<string, PageTextFields[]> = {
  pregnancy_60: [
    {
      page: 1,
      fields: [
        { x: 0.1, y: 0.2, width: 0.8, label: 'Заголовок' },
        { x: 0.15, y: 0.35, width: 0.7, label: 'Дата' },
        { x: 0.1, y: 0.5, width: 0.8, label: 'Основной текст' },
      ],
    },
    {
      page: 2,
      fields: [
        // Координаты для страницы 2
      ],
    },
    // ... остальные страницы
  ],
};
```

## Приоритет работы системы

1. **Если найдено текстовое поле** - текст позиционируется в этом поле с правильными координатами начала
2. **Если поле не найдено, но есть line guides** - используется привязка к линиям (Y координата)
3. **Если ничего не найдено** - используется стандартное позиционирование по клику
