# Руководство по определению координат текстовых полей

## Обзор

Это руководство поможет вам определить координаты текстовых полей для каждой страницы альбомов, чтобы текст автоматически позиционировался в правильных местах.

## Что такое координаты текстовых полей?

Координаты текстовых полей определяют, где должен начинаться текст на каждой странице альбома. Они хранятся в нормализованном формате (0.0 - 1.0), что позволяет им работать на экранах любого размера.

## Формат координат

```typescript
{
  x: number,      // Горизонтальная позиция (0.0 = левый край, 1.0 = правый край)
  y: number,      // Вертикальная позиция (0.0 = верхний край, 1.0 = нижний край)
  width: number,  // Ширина поля (0.0 - 1.0, относительно ширины страницы)
  label?: string  // Описание поля (опционально, для отладки)
}
```

## Как определить координаты

### Метод 1: Визуальный анализ

1. Откройте изображение страницы альбома в графическом редакторе (например, Photoshop, GIMP, или онлайн-редактор)
2. Определите места, где должен начинаться текст
3. Вычислите нормализованные координаты:
   - `x = (позиция_от_левого_края_в_пикселях) / (ширина_страницы_в_пикселях)`
   - `y = (позиция_от_верхнего_края_в_пикселях) / (высота_страницы_в_пикселях)`
   - `width = (ширина_поля_в_пикселях) / (ширина_страницы_в_пикселях)`

### Метод 2: Использование приложения

1. Откройте альбом в приложении в режиме редактирования
2. Нажмите на место, где должен начинаться текст
3. Запишите координаты из консоли разработчика или используйте инструмент отладки

### Примеры координат

#### Пример 1: Поле в левом верхнем углу
```typescript
{
  x: 0.1,      // 10% от левого края
  y: 0.15,     // 15% от верхнего края
  width: 0.3,  // 30% ширины страницы
  label: 'Дата'
}
```

#### Пример 2: Поле в центре страницы
```typescript
{
  x: 0.2,      // 20% от левого края
  y: 0.5,      // 50% от верхнего края (центр)
  width: 0.6,  // 60% ширины страницы
  label: 'Основной текст'
}
```

#### Пример 3: Поле в правом нижнем углу
```typescript
{
  x: 0.6,      // 60% от левого края
  y: 0.85,     // 85% от верхнего края
  width: 0.35, // 35% ширины страницы
  label: 'Подпись'
}
```

## Структура файла координат

Файл `constants/text-field-coordinates.ts` содержит координаты для всех альбомов:

```typescript
export const TEXT_FIELD_COORDINATES: Record<string, PageTextFields[]> = {
  pregnancy_60: [
    {
      page: 1,
      fields: [
        { x: 0.1, y: 0.2, width: 0.8, label: 'Название' },
        { x: 0.15, y: 0.35, width: 0.7, label: 'Дата' },
        // ... другие поля
      ],
    },
    {
      page: 2,
      fields: [
        // ... поля для страницы 2
      ],
    },
    // ... другие страницы
  ],
  // ... другие альбомы
};
```

## Процесс заполнения координат

### Шаг 1: Подготовка

1. Убедитесь, что у вас есть изображения всех страниц альбома
2. Откройте файл `constants/text-field-coordinates.ts`
3. Найдите или создайте запись для нужного альбома

### Шаг 2: Анализ страницы

Для каждой страницы:

1. Откройте изображение страницы
2. Определите все места, где должен начинаться текст
3. Для каждого места определите:
   - Где начинается текст (x, y)
   - Какую ширину должно иметь поле (width)
   - Описание поля (label, опционально)

### Шаг 3: Запись координат

Добавьте координаты в файл:

```typescript
{
  page: номер_страницы,
  fields: [
    { x: ..., y: ..., width: ..., label: '...' },
    // ... другие поля
  ],
}
```

### Шаг 4: Тестирование

1. Откройте альбом в приложении
2. Попробуйте добавить текст в местах, где определены координаты
3. Убедитесь, что текст позиционируется правильно
4. При необходимости скорректируйте координаты

## Советы

1. **Точность**: Координаты должны быть точными до 2-3 знаков после запятой
2. **Ширина полей**: Учитывайте, что текст может быть разной длины, поэтому задавайте достаточную ширину
3. **Отступы**: Оставляйте небольшие отступы от краев страницы (обычно x начинается с 0.05-0.1)
4. **Множественные поля**: На одной странице может быть несколько текстовых полей
5. **Тестирование**: Всегда тестируйте координаты после их определения
