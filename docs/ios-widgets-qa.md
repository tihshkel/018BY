# Виджеты 018BY

Обновление от 10 октября 2026. По просьбе владельца проекта сборка, тесты, линтер и симулятор не запускались.

## Оформление и назначение

Палитра повторяет `constants/design-tokens.ts`: белые поверхности, основной текст #3D3D3D, вторичный #8A8A8A, розовый #F194A2, мягкая подложка #FDF0F2. Системный шрифт для интерфейса, книжный шрифт для вопросов и отдельных заголовков, скруглённые карточки и контрастный текст. Фирменные детали: мини-обложки со слоями бумаги и разными символами/оттенками для категорий, листок календаря с реальной датой события, штамп для заметки, луна и звёзды для беременности. Полоска внутри значка альбома и линейные шкалы прогресса убраны; действия оформлены нейтрально, розовый остаётся небольшим акцентом. Для тёмного оформления используется отдельная палитра. Системные отступы отключены, домашние виджеты задают один внутренний отступ: 14 pt в маленьком размере, 16 pt в остальных. В маленьком размере верхняя строка обходится без повторного бренда, чтобы название помещалось. Средний виджет альбомов показывает две отдельные мини-карточки, большой — три альбома, Extra Large — сетку до пяти; ссылка на полный список сохранена. Для экрана блокировки предусмотрены отдельные компактные состояния, включая пустые.

| В галерее | Сценарий | Размеры |
|---|---|---|
| Ещё одна страница | Следующая незавершённая страница последнего активного альбома | Small, Medium, Large, Rectangular |
| Момент дня | Ежедневный вопрос с учётом категории альбома и переход к заполнению | Small, Medium, Inline |
| Мои альбомы | Личный список историй; отдельные ссылки у каждой строки | Small, Medium, Large, Extra Large |
| Важные даты | Ближайшее событие, затем следующие даты | Small, Medium, Large, Inline, Circular |
| В ожидании тебя | Неделя, день, ПДР и повод записать воспоминание | Small, Medium, Large, Circular, Rectangular |
| Для вашей истории | Реальные сообщения; без сообщений — приглашение продолжить альбом | Small, Medium, Large, Inline, Rectangular |

Идентификаторы `kind` сохранены: уже добавленные виджеты получают новое содержание. Галерея использует демонстрационные данные, домашний экран — данные пользователя.

## Данные и переходы

- Источник Expo prebuild: `ios-widgets/`; те же изменения внесены в текущий target `ios/018BYWidgetExtension/`.
- App Group: `group.com.tihshkel.x018BY.expowidgets`, ключ `WidgetSnapshot`.
- Данные страниц читаются через `loadPageValuesMapMerged`, включая последние сохранения отдельных страниц.
- Процент считается по доступным для заполнения страницам. Служебные, заблокированные и исключённые из экспорта страницы не считаются незавершёнными. Количество фото не используется как приближение процента.
- Для поиска продолжения рассматриваются все альбомы. В список виджета передаются пять последних активных альбомов; общий счётчик не ограничен пятью.
- Если структура альбома ещё не создана, виджет предлагает начать с первой страницы и открывает сам альбом.
- `app018by://widget-open?id=…&mode=continue` заново читает сохранённый альбом, выбирает актуальную незавершённую страницу и соответствующий редактор текста или фото.
- `app018by://widget-open?id=…&mode=album` открывает конкретный альбом с актуальными параметрами внутреннего блока и обложки.
- Если альбом удалён, переход ведёт к остальным историям или выбору нового альбома. Без имени пользователя переход возвращает в обычный стартовый сценарий приложения.
- Пользовательские даты, история уведомлений и выбор альбома открывают существующие экраны `reminders-list`, `notifications`, `my-stories`.
- В inbox нет состояния прочтения. Счётчик означает число сообщений за день, а не число непрочитанных; отображение списка ограничено тремя сообщениями.
- Даты пересчитываются нативно относительно локального календаря. Расписание включает текущую запись и семь следующих полуночей: меняются вопросы дня, срок беременности и ближайшее событие, вчерашние сообщения перестают считаться сегодняшними.
- Сохранение, удаление, возврат в приложение и уход в фон обновляют snapshot. Повторный запрос во время чтения приводит к повторному чтению последних данных. Выход из аккаунта отменяет публикацию ранее начатого snapshot.
- iOS управляет моментом перерисовки и обновления виджетов; запрос на перезагрузку не означает мгновенную перерисовку.

## Для ручного просмотра владельцем

Нужна новая нативная iOS-сборка приложения с расширением, включая новый маршрут `widget-open`. Expo Go не запускает это расширение. После установки откройте приложение для передачи данных.

1. В галерее просмотрите шесть виджетов; выберите маленький и средний варианты.
2. Создайте альбом без заполненных страниц: продолжение должно предлагать начать историю.
3. Заполните или сохраните черновик одной страницы; вернитесь на домашний экран и откройте её из виджета.
4. Откройте текстовую страницу и страницу с фотографиями из виджета продолжения.
5. В среднем/большом виджете альбомов нажмите на разные строки: каждая должна открыть свой альбом.
6. Удалите рекомендованную страницу или весь альбом и нажмите на ещё не обновившийся виджет.
7. Для даты сегодня отображается «Сегодня», завтра — «Завтра»; после полуночи прошедшее событие уступает место следующему.
8. Укажите ПДР, затем измените её; откройте дневник из виджета. После ПДР не показывается отрицательный обратный отсчёт.
9. Получите больше трёх сообщений за день: счётчик отражает весь день, список — последние три. После полуночи «Сегодня» не относится ко вчерашнему сообщению.
10. Посмотрите светлое, тёмное и тонированное оформление, большие шрифты, iPad Extra Large и все варианты экрана блокировки.
11. Выйдите из аккаунта во время сохранения: прежние альбомы не должны вернуться в виджеты.
